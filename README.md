# Factory Assistant Frontend

This is the repository for the Factory Assistant frontend — the web UI for the
Factory Assistant industrial monitoring appliance.

Factory Assistant is based on Home Assistant.

## Development

- Initial setup: `script/setup`
- Development: `script/develop`
- Production build: `script/build_frontend`
- Gallery: `cd gallery && script/develop_gallery`

This fork tracks the upstream Home Assistant frontend, so the upstream
[frontend development instructions](https://developers.home-assistant.io/docs/frontend/development/)
apply to the codebase.
